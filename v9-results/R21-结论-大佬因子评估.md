# R21 严格 OOS 结论 — 大佬因子评估（2026-08-09）

## 一句话结论（数据支持，已颠覆上一轮乐观判断）

**补全 BASELINE 后，大佬因子在 R21 OOS 上没有产生正 alpha。**
上一轮"SMART_BUY/SMART_MOD 跑赢基线 +2%+"是 **假象**，原因是 BASELINE 缺了后段高收益窗口（wi39-42）被低估。

---

## 实验设置（防作弊）

- 数据：`backtest/data/trading_by_date_real414_v7.json.gz`（干净权威数据，550,365 条）
- 框架：`scripts/exp_strict_oos.py`，ROUND=21，22 个 OOS 测试窗口
- 4 候选：
  1. `KC_AGGRESSIVE_BASELINE` — 基线（无大佬因子）
  2. `KC_SMART_BUY_15` — 大佬信号作独立维度，weight=15
  3. `KC_SMART_BUY_25` — 大佬信号作独立维度，weight=25
  4. `KC_SMART_MOD` — 大佬信号作加减分修饰符（不占维度权重）

## 数据来源（严格说明）

- GitHub Actions run `31308921476`（head `dd49383`）：24 backtest job **全部 success**，但 aggregate job 的 git push 失败。
- 直接从该 run 下载全部 artifacts，得到各候选的逐窗口结果。
- **ci0 (BASELINE) 只产出 wi21-38（18 窗）**，wi39-42 缺失（GitHub runner 上 ci0 后段窗口每个 >300s 超时被杀）。
- 用**重叠 18 窗逐窗口对比**作为最公平依据（不受缺窗口影响）。

## 核心结果

### 重叠 18 窗（wi21-38）逐窗口对比 — 最公平

| 候选 | 跑赢 BASELINE | 平均超额 vs BASELINE |
|---|---|---|
| `SMART_BUY_15` | 8/18 (44%) | **-0.270%** |
| `SMART_BUY_25` | 9/18 (50%) | **-0.121%** |
| `SMART_MOD` | 0/18 (0%) | **+0.000%**（与基线完全相同）|

### 关键事实

1. **`SMART_MOD` 与 `BASELINE` 在所有窗口收益完全一致**（wi24-38 逐窗口数值全同）。
   → 修饰符逻辑（回调 -10~-3% + topgain>=4 + net_buy>=1 → +0.5）在 OOS 中**零触发**。
   信号文件 `data/smart_money_signals.json` 实际含 588 个强信号（214 日期，覆盖测试期），但**没有信号在回测中被应用**（匹配失败 / 持仓过滤 / 条件不满足）。

2. **BASELINE 缺失窗口是高收益窗口**：wi41 参考值 +23~33%（ci1/ci3 在该窗 +23~31%）。
   用 ci1/ci3 敏感性补全 wi39-42 后，**BASELINE 22 窗 avg = 3.27~3.59%**，追平甚至反超 3 候选（3.09~3.37%）。

3. **上一轮"大佬因子 +2.2%"是假象**：只因为 BASELINE 缺了 4-6 个高收益后段窗口被低估。

## 最终判断

- **大佬因子（维度模式 / 修饰符模式）在 R21 OOS 上无正超额**。
- SMART_BUY（维度模式）略跑输基线；SMART_MOD（修饰符）完全无效（结果与基线相同）。
- **不建议继续以大佬因子作为增强主方向。**

## R22 建议方向（供参考）

1. 不再主推大佬因子增强。
2. 转向其他 alpha 来源：动量/质量维度调参、行业轮动、更细择时。
3. 若要保留大佬因子，先排查 MOD 修饰符为何零触发（信号匹配链路可能断）。
